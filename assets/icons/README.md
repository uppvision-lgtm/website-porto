# UI icons

Source: https://github.com/lucide-icons/lucide

Pinned revision: `3fef7aca71a50acc54bd2f24f0cc4747c22aa6d2`.

Official SVG files downloaded from `icons/`. Used under the ISC license and applicable Feather MIT notices included in LICENSE. Colors follow each page through CSS masks; SVG path data is unchanged.

`mapping.json` maps legacy decorative glyphs to the local SVG assets. Static HTML uses explicit icon spans; `js/icons.js` renders icons in demo-generated content.
