Godam.

(komen, edit video, upload — tiga mesin, satu antrean.)

Suite otomasi Instagram: auto komen ber-AI dengan tiga pilihan nada, auto edit video — tempel link, jadi Reels 9:16 dengan lower-third ala berita TV — dan auto upload lewat browser yang meniru manusia. Semua digerakkan antrean yang sama: frontend Next.js, API FastAPI, worker Celery + Redis, browser Playwright, render ffmpeg, otak DeepSeek.

Tiga Mesin, Satu Antrean.

Semua fitur jalan lewat pola yang sama: kirim job → masuk antrean → dikerjakan worker → pantau status. Nggak ada yang nunggu diam-diam.

① Auto Komen

Link postingan → FastAPIPOST /api/start-job + tone → DeepSeekkomen per nada + fallback lokal → Playwrighttempel komentar → Instagram✅

② Auto Edit Video

Tempel linkIG / TikTok / YouTube / MP4 → yt-dlpunduh sumber → DeepSeekhook 3 baris ala berita → FFmpeg 1×kanvas 9:16 + overlay + intro/outro → output.mp4bisa diunduh ✅

③ Auto Upload

Video + caption → Supabasesigned URL / multipart → Playwrighttiru manusia: Buat → caption → Bagikan → Instagramreel tayang ✅

Tiap task bisa dipantau lewat endpoint status masing-masing. Health check di /health, dokumentasi interaktif otomatis di /docs.

API-nya Kayak Gini.

Empat endpoint utama — satu per mesin. Kirim job, pantau statusnya, ambil hasilnya.

$ curl -X POST http://localhost:8000/api/start-job -d '{"target":"…","tone":"netral"}' # → komen ber-AI sesuai nada, batch 10, maks 100 per job $ curl -X POST http://localhost:8000/api/video/hook -d '{"naskah":"…"}' # → DeepSeek merapikan jadi 3 baris lower-third gaya berita $ curl -X POST http://localhost:8000/api/video/jobs -d '{"link":"…","template_id":"reels"}' # → yt-dlp unduh sumber → render 9:16 → unduh output.mp4 $ curl -X POST http://localhost:8000/api/upload/start -d '{"username":"…","caption":"…"}' # → browser Playwright mengunggah: Buat → caption → Bagikan

✦ Fitur Favorit: Live Login Assist

Pas Instagram ngeblok login otomatis dengan CAPTCHA/checkpoint, panel menyiarkan browser login langsung ke halaman web — frame di-refresh ±450 ms, klik kamu diteruskan ke browser sungguhan. Selesaikan CAPTCHA manual, sessionid otomatis dipakai untuk job berikutnya. Ada tombol Ketik & Enter buat challenge teks.

Kebijakan retry-nya sopan: password salah & akun nggak ditemukan nggak di-retry otomatis, retry pertama nunggu 300 detik, dan worker nggak usil ambil task baru sebelum task lama beneran selesai. Satu browser per task, selalu ditutup di finally.

✦ Edit Video: Lower-Third ala Berita TV

Tempel link (IG/TikTok/YouTube/MP4) → yt-dlp mengunduh sumbernya → naskah kamu dirapikan DeepSeek jadi tiga baris lower-third gaya berita televisi: headline–detail–pesan, maksimal 36 karakter per baris, huruf kapital semua. Kalau AI lagi ngambek, ada cadangan ringkasan sederhana — fitur ini nggak pernah gagal total.

Render digabung jadi satu proses ffmpeg: video sumber dipasang ke kanvas template 1080×1920, ditumpuk overlay PNG & teks, lalu disambung intro/outro — sekali encode, tanpa penurunan kualitas berlapis. Progres render keluar realtime, ada guard timeout 30 menit, dan hasilnya bisa langsung diunduh dari panel.

Dua Jalur Produksi.

Monorepo yang sama, tinggal pilih selera deploy.

  1. Jalur Cloud

    Browser → Vercel (frontend + proxy API) → Render Web Service (FastAPI) → Upstash Redis ↔ Render Worker (Celery + Playwright). API dan worker dipisah sengaja — proses Playwright nggak cocok dengan batas serverless.

  2. Jalur VPS

    Push ke main → GitHub Actions SSH ke VPS Hostinger → git pull + docker compose. Secret (env, SSH key, session) nggak pernah ikut commit; frontend meneruskan request ke backend lewat BACKEND_API_URL.
