(20 HP Android di satu box, dikendaliin dari satu layar Mac.)

Cara Kerjanya, Singkat Padat.

Dari box berisi HP sampai browser Mac — empat langkah.

  1. Box × hub × Mac

    Board Android berjejer di box 20-slot lewat hub USB. Pengendali box melapor via serial CH340, sementara HP kebaca ADB (libusb) — dua jalur data yang berbeda, biar status slot fisik nggak ketukar dengan perangkat yang terdeteksi.

  2. Pemindaian otomatis

    Tiap 5 detik panel memeriksa semua perangkat: model, versi Android, baterai, ukuran layar, status izin USB. Slot yang belum kedeteksi nggak dianggap rusak — cuma "belum terbaca", lengkap dengan panduan diagnosa.

  3. Streaming H.264 realtime

    Layar asli tiap HP dikirim scrcpy-server → FFmpeg → WebSocket, didekode langsung di browser. Satu sesi streaming per board, tanpa buffer dan tanpa file rekaman — ditutup begitu layar ditutup.

  4. Kontrol kayak HP beneran

    Klik = tap, seret = swipe atau long-press, scroll mouse = geser. Tombol Back/Home/Recent, wake/sleep, volume, kirim teks, unduh screenshot PNG. Pilih beberapa HP → kontrol sinkron ke semuanya sekaligus.

✦ Dibangun Paranoid (dengan Sayang)

Layanan cuma mendengarkan 127.0.0.1 — nggak pernah ke internet. API & WebSocket dilindungi cookie lokal + pemeriksaan origin. Kunci ADB nggak pernah dikirim ke browser atau ikut repo. Password Instagram cuma hidup di memori selama proses, kolomnya dikosongkan setelah dikirim, dan nggak masuk inventaris/log.

Internet HP diambil lewat USB (gnirehtet), kunci board tambahan dimuat otomatis dari lokasi khusus, dan semua path binary bisa dioverride — panel ini didesain buat dipindah-pindah laptop tanpa drama.
